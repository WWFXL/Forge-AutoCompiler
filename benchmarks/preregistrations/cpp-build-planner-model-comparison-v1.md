# 共同规划出口修复后的规划模型比较

2026-11-05，Issue #685。用户要求按顺序修复方案接收、优化规划指令，并明确允许使用RichLab对照。新增支出自行限定为2美元硬上限，正式启动起最多2小时，不续用旧实验余额；16槽一次执行，不自动重试、不补槽。未知用量、响应身份异常或清理失败停止整批。格式纠正是一次显式计费请求，不是服务重试。

## 问题和固定处理

同一个修复后Harness下，改变初始规划模型路由是否改善方案交付、主构建和完整完成，以及成本和耗时？

jsoncpp/libsrtp/libite/highwayhash×两重复×Flash/RichLab规划，共16槽；项目内顺序交替、第二重复反转。全部为已开发暴露项目，属于开发对照；不能把两个重复当成八个独立项目。两组均使用经验Forge，同一冻结24条经验库，每个规划/恢复任务开始只检索一次、最多两条/4096字节；没有精确方案复用、新提炼或在线更新。原任务、源码、镜像、2CPU和独立验收保持；测试按实际构建系统选作者入口，完整结果与主构建分别报告。

规划分别为deepseek-flash thinking low与RichLab gpt-6-astra请求路由、Responses API、reasoning low；沿用用户接受的响应gpt-5.6/gpt-6-astra，实际标签逐响应披露，不能证明后端为官方Astra。两者工具选择均auto、最大输出32768、HTTP超时240秒、SDK重试0。两组失败恢复均为Flash，避免同时改变恢复模型。接口/服务与模型共同形成处理，不能解释为纯模型参数能力因果。

共同接收先记录原响应和用量：工具方案由原ToolStrategy校验；单一完整正文JSON经过同一SimpleBuildActions校验；语法、字段或缺少方案共享最多一次反馈，第二次错误停止。允许一次外层JSON代码围栏，不猜括号、不补字段、不从说明文字抽取命令。经验不改变方案结构或成功标准。原E43失败及后层未观察保持，不把离线回放计为模型成功。

## 费用、停止与结果

Flash每百万输入/输出0.30/1.20美元，按全输入缓存未命中保守估费；RichLab沿用用户明确提供的输入/输出各1美元/百万Token。全部读取、初始规划、纠正、失败、恢复计入，历史经验制备费0.095129美元单列不重复支付。单槽最多0.40美元，下一完整响应按最大100000Token和最高单价保守预留；全批硬上限2美元。请求/Token/时限沿用共同执行器，耗尽即保留失败或未观察。

主要报告16槽完整分母的方案交付、主要构建、完整任务、请求/费用/耗时，另外报告格式错误/纠正、正文接收、读取次数、初始规划和恢复分项费用。小样本仅描述观察，不作显著性、一般模型排名或经验/状态独立增量主张；旧新版完整率差值不当修复因果。先完成七份原响应的离线回放及代表性真实构建，再固定manifest并采集；代码/依赖哈希、来源、授权及原始响应日志独立保存。
