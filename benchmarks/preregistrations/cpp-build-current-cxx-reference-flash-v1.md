# 当前Forge与CXXCrafter社区版阶段性参考

研究问题：当前模型规划Workflow与可运行CXXCrafter社区版在三个已见构建任务上的完成情况、总模型费用、请求和时间有何差异，失败暴露了哪些改进空间？本批仅为当前实现参考，不评价Forge最终能力，不冒充论文原版复现或独立状态感知因果实验。

- 固定simdutf/CMake、tinyxml2/Make、check/Autotools各一次，两策略共六槽；调度在manifest冻结。失败保留、不补槽、不自动重试HTTP/SDK；原生失败后修改Dockerfile属于方法本身。
- 两边使用同一源码归档、固定autocompiler:gcc13镜像、2CPU、deepseek-flash thinking low、32768输出上限、原任务全部测试与精确交付。Forge沿用现有统一装配与恢复接口。所有初始读取、规划、审阅、Judge、失败与恢复模型费用均计入；按输入0.30/输出1.20美元/M保守估算，非账单。
- CXXCrafter冻结社区版实际src快照及上游revision（含既有用户运行修复），不改原工作树；保留Parser/CCScanner、文档模型选择与总结、Generator/Review、Docker构建、两级Judge及最多10版Modifier。SDK捕获完整usage，关闭SDK自动重试，收窄文档选择eval为literal_eval。宿主输出路径独立，源码只建立无HEAD的原归档Git索引，copytree保留原符号链接；这些属于输入及运行适配。
- 共同用户任务追加到原生生成提示，要求固定路径/镜像、全部测试、原源码及测试不改、2workers。原生Judge成功后外部执行原固定测试、前后原文件/链接核对、相同精确暂存和Forge结构分类器；通过后无缓存从同源码Dockerfile重建并再验、比较交付路径/类型/大小/哈希。外部失败不反馈额外恢复。分别报告自报成功、外部任务完成和未观察。
- 内部Judge、验证反馈、工具可见性和材料组织仍有差异；因此是任务适配下的系统参考，不能将差值归因于单一规划算法或状态感知组件。三项目各一次不足以推总体排名或显著性；结果好坏均用于定位后续组件实验。
- 本阶段自限新增4美元，和之前22槽0.4366236美元共用原10美元授权；原截止UTC2026-10-27T12:44:30，不重置。新槽需剩1800秒，CXX新请求需900秒，单请求240秒；原Forge请求/执行窗口保持。未知用量按0.80美元预留并停止整批，身份异常或实际清理失败也停止付费。CXX每槽最多1美元，Forge每槽预留3美元；原预算耗尽/时间不足则余槽明确未观察。
- 原始证据独立create-once，包含快照、原请求/响应、日志、Dockerfile版本、原/重建检查及费用；最终一次封存。完成标准为六槽终结或触达预定停止，并形成可引用结果表和失败分析，不以新增测试/文档数代替科研结果。
