# 简洁目标下四方法系统比较 v1

2026-11-04，Issue #677。身份 `cpp-build-simple-system-comparison-flash-v1`。
本协议准备不读取凭据、不调用Provider；正式数据仍未观察，须绑定新的用户授权。

## 研究问题与比较

RQ-S：在作者推荐或默认主要构建目标下，Forge的规划/Workflow/失败恢复与强工具Agent、CXXCrafter社区实现相比，主要构建、完整完成、全程费用和耗时有何取舍？

RQ-E：保持Forge主体相同，冻结跨项目经验的一次注入是否减少规划/恢复探索，改善费用或完成情况？

四方法：A `forge`，模型规划→实际状态/Workflow→必要时返回修订方案；B `forge_experience`，同A加已有跨项目状态/目标检索；C `strong_tool_agent`，由Agent决定逐条命令并提交实际成功recipe；D `cxxcrafter`，现有社区原生Parser/Generator/Modifier/Judge与Dockerfile闭环。D是完整系统参考，不冒充论文原版；工具/上下文与镜像执行差异保留，系统差值不能全归于状态感知。

## 样本、来源与顺序

固定六项目×两重复×四方法=48槽，每方法12槽：CMake的jsoncpp/miniz，Make的pigz/highwayhash，Autotools的libite/libsrtp。源码commit、归档SHA、主要组件参考、作者测试和暴露登记见 `benchmarks/fixtures/simple-system-comparison-v1/tasks.json`。以自然主要ELF/ar产物、三系统各两项、已有源码和经验来源族隔离选定，不根据本批模型成败删换样本。4个C项目（miniz作者测试含C++）、2个C++项目，不能说覆盖大型复杂C++仓库。

全部已有源码/任务开发或方法结果暴露，jsoncpp/pigz/libite已有本版工程实跑；不称holdout、未见仓库或训练未见。经验库12来源轨迹/8项目族、24条既有结构化经验，与本批六族完全分离。历史制库费单列，0新提炼。没有本版精确成功方案输入；本批新保存的成功方案不供后续重复。只回答跨项目经验，不拼接同项目复用成功率。

按重复1六项目、重复2六项目运行，各项目内采用四个Williams顺序 ABCD位置变换：`A B D C`、`B C A D`、`C D B A`、`D A C B`，依次循环三次。每方法每位置3次、每一有向相邻方法3次；重复串行、无容器/依赖安装缓存共享。基础镜像固定不可变ID；宿主Docker层/网络/Provider缓存可能存在时变影响，顺序平衡不能消除全部漂移。

## 共同输入、资源和结果层

公开输入仅指定版本源码、构建系统、Linux架构/镜像/2并行资源及SIMPLE_GOAL：依据作者推荐或默认方式构建主要程序或库，保持原源码/测试。不给参考成功命令、精确产物目录或逐项目测试合同，不加入Debug/静态/benchmark等额外目标。原作者默认带入的目标保留，不让方法关闭主要组件。默认目标不明确时记录歧义，不事后换任务。

私有参考只声明主要组件及版本别名；同一逻辑库的静态/共享形式均可，实际产物定位复用独立检查。作者测试在主构建被接受后由外部执行，不回送模型。CMake从实际顶层CMakeCache/CTest注册启动完整CTest，串行且零测试报错，不固定`build`路径；Make/Autotools运行作者原入口。未构建测试、实际测试失败、超时、未观察分报；不把关闭默认测试而没测的情况记通过。

基础镜像、源码、网络 `compile_network_wwf_v1`、root包安装权限、2CPU和Flash low相同；CTest独立串行。Forge/C保留严格Shell和生成物清理、保护原输入、完整有序重放。D保留原生宿主解析、Judge与Dockerfile工具，固定FROM、源码位置/资源，关闭缓存重建，跨镜像核对原文件内容/链接/权限；不声称其inode/ctime保护与Forge相同。D内部Docker RUN超时和原生循环不同于Forge单命令180秒/主Workflow1200秒内部预算；共同总槽上限2700秒和请求/Token/费用上限相同，属于完整系统条件，非等工具/等内部动作预算消融。

结果分层：命令退出、主要组件构建、精确交付、作者测试、干净重放、源码保持、清理与完整完成；失败不覆盖前层成功。构建未完成时后续为未观察，不填失败。原测试失败时可观察构建重放，不能称测试重放通过。通过清理才记完整完成。

## 模型、预算与停止

全部模型请求 `deepseek-flash`，thinking enabled、reasoning low、最多32768输出Token、SDK自动重试0、HTTP timeout240秒。允许响应名仅 `DeepSeek-V4.1-Flash-1017` / `deepseek-flash`，不新增RichLab。初始、读源码、结构输出、失败与恢复、D所有Judge/Modifier均计入。

单槽最大估费1美元、96请求、100万recorded Token停止阈值；已发生的末响应完整计量、不截断费用。Forge每请求消息/工具沿既有字节上限及单响应100000 recorded Token；D沿SDK动态按请求字节加8192余量/32768输出预留，不冒充同上下文处理。每请求费用预留只决定是否准入，**不是主动等待时间**。请求剩余600秒才准入；新槽需900秒，最多2700秒、原作者测试180秒、Forge重放600秒，末尾清理另留120秒。D无缓存重建沿原执行/窗口边界，`replay(240)`只作准入、不是声明其硬执行时限。

建议用户授权共享新增10美元硬上限、确认起8小时（准备若发生于确认后计入）；当前尚未授权。不存在不限额或旧余额续用。授权文件绑定本manifest的SHA、身份、原用户答复、确认/截止和无自动重试，校验通过后才读取环境凭据。总费依次扣除前槽全部已知费用，下一槽最多用剩余额度与1美元中的较小者。未知用量、模型身份异常、清理失败停止整批；普通任务失败/截断保留后继续后续槽，不自动重试或补槽。费用/时窗耗尽保留已观察与未观察，不能宣称48次全部完成。

意外中断/未闭合槽保存原件并停止；汇总`closed_slot_cost_usd`只是已闭合槽小计，不能将未闭合槽当免费，需先按原请求/响应单独结算。中断不以新目录重跑同身份；后续由用户决定新范围。

## 分析与论文用途

主要结果为固定12槽/方法的主要构建完成数、完整完成数、全程估费、请求/Token及累计耗时；各层通过/失败/超时/未观察完整保留。到主构建耗时须包含准备与初始规划；旧Workflow局部计时不得直接与全工具总计时比较。另分初始规划、恢复、Shell、作者测试、交付与重放（某原生阶段无法拆分时标未观察，不补造时间）。A/B按项目-重复配对，按项目汇总方向；重复不是独立项目，不作大样本显著性宣称。全部完成的配对耗时仅辅助，必须同时显示全分母、失败成本和超时。

保留A/B/C/D各自优势、劣势及具体自然失败案例，不以全指标胜出为硕士研究继续的门槛。经验效果含历史制库费另列/累计摊销；在线节约不等于首次总费更低。检索命中/动作相似不是采纳因果。自然状态触发/后缀重执行次数仅作机制观察，没有相同初始方案对照就不当状态因果。

主报告用于新版简洁任务系统结果；旧E01/E30/E33/E35–E41及论文v0.6按原版本保留，不作废、不冒充新版效果，不合并分母。小增强先做组件配对，主行为变化才补新系统版本。
