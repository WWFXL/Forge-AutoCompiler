# 新项目上的统一三系统比较

跟踪Issue #646。阶段为免费任务准备；本身份尚未授权调用Provider。候选SHA、预算及有效截止须在启动前绑定，E30旧授权和余额不续用。

## 研究问题与预期用途

当前模型规划＋状态Workflow＋失败Agent在未用于当前方法调试的新项目上，相对强工具Agent与CXXCrafter社区版有什么完整完成、模型费用和耗时取舍？补充E30已开发样本的外部有效性。提升很小、持平或存在代价都如实解释，不把全指标获胜作为研究继续条件。

本批是完整系统比较。配置直接动作是否独立有益由同方案组件消融回答；三系统独立规划的结果不能用来估计纯状态组件效应。

## 选样、暴露和固定任务

在读取新方法结果前登记八候选：jsoncpp、PEGTL、inja、highwayhash、libsigcplusplus、libxcrypt、libsrtp、FiniteStateEntropy。五个C++、三个C；三CMake、二Make、三Autotools。固定版本、原作者任务和排除／参考失败在`benchmarks/fixtures/new-project-comparison-v1/`登记。选择依据是可定义Linux任务、原作者测试与独立交付，属于有目的样本，不是随机总体抽样。

历史检索范围为基线`e0b7eac682807facc890488cc10de55ae4767f79`的benchmarks/docs/research/scripts；先查询完整仓库名，再核对别名。没有精确仓库命中不证明Git全历史未见、模型训练未见或项目族独立。本阶段任务准备与人工参考本身已暴露；只称“新于当前方法调试”，不称完全盲holdout。保持当前方法代码，不用这些参考反向调方法。

八候选中libxcrypt在原作者`getrandom-fallbacks.c`明确规定：平台具有arc4random_buf时返回77，默认参考为47 PASS＋1原生SKIP。保留该参考及初次缺libltdl-dev的失败，不把原生不适用当作方法失败；本批主比较保持全部原测试实际通过的口径，libxcrypt不进入效果分母，不另选项目替补。其余七项（五C++、二C；三CMake、二Make、二Autotools）×两重复×三方法=42预定槽，每方法14槽。六种方法顺序轮换，第二重复错开三种，完整调度在manifest固定；不依新方法结果换项目、补槽或续跑失败身份。重复不是独立项目；源码族和共同上游材料的潜在关联披露，不以这些项目当独立总体证据。

三方得到同一完整任务：精确源码、必要依赖资源、CMake Release和build目录、原作者测试入口、固定配置要求、精确交付、原文件与链接不变、同镜像干净重放和清理。源码与原测试不可修改；允许新增标准生成文件。参考失败和修复记录单列，正确参考配方不提供给正式Agent。

## 方法与公平条件

直接复用E30的`scripts/forge_build_system_comparison.py`及其运行组件，不修改旧manifest、方法、冻结证据或裁判。

- Forge：模型只读规划→共同装配→GoalStateWorkflow→一次有依据的BOOL直接修订或同一失败Agent→完整验证。
- 强工具Agent：同一共同任务、模型与计量Harness，自行使用原构建工具→固定测试／自动配方提交。作为主要对照。
- CXXCrafter：同一已固定社区快照，保留原生Parser／Generator／Modifier／两级Judge及最多十版Dockerfile；共同外部验收失败不再反馈Modifier。作为外部实现参考，非论文原版排名。

原不可变镜像、root用户、网络与安装真实依赖权限一致，均2个构建作业。CXX CPU affinity和Forge quota实现差异保持披露；工具集合、内部反馈与决策上界不相同，不称同Harness。JSONCPP原测试会写共享中间文件，固定全部CTest串行`-j1`，三方一致，未删减测试；其他测试沿作者入口和两作业环境。具体任务配置和额外资源以fixture为准，不向单一方法提供隐藏信息。

CMake状态增强只处理现有解析器可识别的显式BOOL目标；Make／Autotools仍是普通阶段Workflow＋失败Agent。没有直接动作时如实报告0，不把系统成本差异全部归为该组件。工具安装引发的版本或环境问题保持真实失败与恢复成本。

## 模型、预算与停止

deepseek-flash、thinking low、输出32768、HTTP240秒、SDK自动重试0，沿E30身份检查。输入0.30／输出1.20美元每百万Token，保守按缓存未命中估算；结果不当实际账单。初始读取／规划、纠错、失败、恢复和CXX审查／Judge全部计入。

建议新增上限10美元、确认起8小时，准备时间计入；此处是拟议上界，不是用户授权。每槽最多3美元、145请求和1000000累计Token等沿原协议；下一请求和下一槽准入照旧。每槽2700秒、最后300秒清理；新槽须剩2700秒，模型请求须剩600秒，完整重放须剩1200＋300秒。窗口并不保证42次全部完成。

未知用量、模型身份异常、清理失败停止整批；无自动重试、无成功替补。时窗／预算未准入的余槽记未观察；已经尝试但因时窗截断者另记，不直接判作方法能力失败。原失败、部分观察和原始响应用量不覆盖。

## 分析与后续组件消融
