# 完整方案与受控工具Agent开发canary v1

跟踪 #486，用户授权 #470；这是开发接线与描述性采集，不是正式效果实验。

研究问题：在四个已经通过人工参考资格的开发任务中，相同源码材料、模型、预算和严格终点下，完整方案+Workflow与有界状态工具Agent是否都能运行闭合？观察调用、修订、失败和费用，决定下一可辨识问题。

固定miniz/md4c/pigz/libite，共8臂，每格一次。顺序为miniz plan/tool、md4c tool/plan、pigz plan/tool、libite tool/plan。每臂干净源码、相同不可变镜像、2CPU。精确源码归档、固定完整测试及交付见manifest；原始普通源码/测试逐文件哈希不变。人工参考配方仅用于零Provider Docker门禁，不交给真实模型。

双方接收相同的<=24000字节源码包、任务与只读源码/失败日志工具。Workflow先生成完整方案并按权威状态执行，最多2次真实失败交接后完整修订；保留不变前缀并使修改后的步骤失效。工具Agent可执行任意合规单阶段Shell、固定测试与严格submit，允许一轮多工具调用并以max_concurrency=1串行执行；明确这是本地受控工具Agent，不等同Codex/Claude Code或所有强Agent。双方都允许新增依赖与诊断，都不能访问/repro、修改原始源码/测试或改变冻结oracle。固定测试退出码及非空输出标记、精确产物集合、同镜像clean replay、重放完整测试和cleanup全部通过才strict completed。重新安装依赖、配置或构建使工具Agent旧测试凭证失效。Shell/replay配方规则复用既有运行时；不同执行器的策略拒绝与异常分别报告，不把它们当能力或机制效果。

每轮模型材料重建为当前权威状态、源码包、最近三个各3000字符的工具反馈和显式剩余预算，完整旧请求/响应/工具反馈独立保存。完整消息（含系统提示）<=50000字节、含结构化输出工具的schema<=8000字节，加8192协议tokens和32768输出的设计上界为98960，低于100000单响应合同。超限在Provider前停止，不截去权威事实以隐式续跑。双方使用DeepSeek Pro thinking/low、32768输出、timeout240、SDK retries0。

每臂最多12请求、400000 recorded-token准入阈值与100000单响应上界（最终授权Token上界500000）、72图步骤/48工具/32命令，节点1200秒含初次规划，单命令180秒，严格验收/重放300秒，cleanup60秒。工具读取和操作按各自实际次数计量；方案中的确定性Shell不伪装成模型工具调用。下一请求保留$0.40，单臂保守估算上限$1.50，阶段整额预留$12，与全部新阶段共享$20。来源资格和历史cJSON费用不重复计入。已知估算与未知预留分开；usage未知立即停止整个阶段、不释放未知预留。响应截断、schema错误、合同/预算错误不隐式重试；失败、部分结果和未执行槽位原样保留。

截止北京时间2026-10-20 07:00（UTC2026-10-19 23:00）；新臂与新请求均保留至少1800秒，最后15分钟只清理审计交接。执行前验证manifest组件、已封存来源资格、源码哈希、同协议8臂零Provider真实Docker门禁及共享预算后，才能读取凭据。运行期间组件不可变，结束复制并核对。

新类型化inventory将普通文件内容与symlink目标文本分别哈希，不遍历链接目录、不读取外部链接目标，支持broken link；审计重新枚举完整文件/链接集合。只适用于本新身份，不修改旧封存格式或失败决定。封存和审计成功后才能结算释放整阶段预算；cleanup失败停止后续臂。

主要描述：逐臂strict状态、固定测试/重放、请求与input/output tokens、保守估算费用、命令、失败类型、修订次数、墙钟和cleanup。失败必须区分模型明确停止、输出截断、策略/合同、执行错误和验收失败。本canary不进入总体成功率、非劣、成本节省比例或机制增量推断。四项目已开发暴露，不能称最终holdout；没有失败/修订激活时如实报告，后续另设计状态/动作分歧，不在相同全成功样本重复挽救。正式研究仍需静态方案/规则消融、强基线与项目族隔离。
