# cpp-build-simple-project-reuse-flash-v1

## 问题与设计
用户2026-11-05要求开启基础Forge与经验Forge比较。估计精确重复任务的成功方案复用，相对每次重新规划的增量。
固定jsoncpp/libsrtp/libite/highwayhash四个开发暴露项目、两重复、两方法共16槽。方法顺序沿用相邻配对、第二重复反转。两组同deepseek-flash thinking low、修复后共同规划Harness、相同公开简洁目标/源码/镜像/资源、相同Workflow与方案式恢复及独立验收。只改变经验处理；无强工具/CXX额外比较，不改变源码/测试。

## 经验边界
基础Forge重新规划；经验Forge按完整公开任务（仅排除plan_id）精确匹配历史已验证方案，匹配则跳过模型规划，Workflow仍实际重新构建/检查/clean replay；失败沿用相同Flash方案式恢复。两组均不注入跨项目建议。方案固定来自E45第一重复Flash的槽1/4/5/8，不按成本或本轮结果挑选；源码/镜像/资源/任务不变。来源inventory为2ffaab2d1b7a9ed689c4ca089c7233f47c26797c8b28f2236c5ed53627326970；各方案SHA和历史来源费用写入manifest。来源曾使用跨项目建议，该成本与制库费另列，不主张经验免费。每次干净构建，不复用二进制、不用本批成功更新后续重复。
两批各自固定16槽，不合效果分母；不把历史来源运行算本轮观察。两重复按项目聚类，四项目为开发样本，不作未见泛化或普遍排名。经验命中不等于动作采纳。

## 指标与费用
主构建/作者测试/交付/clean replay/源码保持/cleanup及完整完成分别记录；未观察不填通过或失败。全部初始读取、规划、结构纠正、失败和恢复费用计入；分报初始规划与恢复请求、方案复用次数、重复读取、到主构建时间与整槽时间。全分母费用与累计时间为主，共同完整配对仅辅助，失败早停不称加速。Flash保守单价输入0.30/输出1.20美元每百万Token，不冒称实际账单。

## 本轮授权与停止
授权依据：当前用户“好的开启比较基础 Forge 与经验 Forge”及会话既有实验/仓库流程授权。新增预算由助手自行从严限定2美元、UTC2026-11-05 00:30:44至02:30:44，两批共享，准备计入。不复用上一轮余额/时窗；全部32次完成后即停止、不自动追加。
单槽上限0.40美元，保留原共同时间/命令/请求资源，不自动重试Provider，不补槽。一次显式结构纠正计费且不视作服务重试。未知用量/响应模型异常/cleanup失败立即停止整批及下一批；普通明确失败记录后继续固定顺序。截止/预算不足不启动新槽，保留未观察。以新manifest绑定源文件哈希和新Git运行revision；正式执行期间不改绑定组件，不改历史raw。
