# 修复后两层经验完整系统比较 v1

## 研究问题

固定 deepseek-flash、简洁公开构建目标和共同独立检查，比较基础 Forge、两层经验 Forge、强工具 Agent 的主要构建完成、完整任务完成、请求、费用和耗时。分别回答已有成功方案的重复任务与无精确方案的新任务上的表现，不将两种工作负载混称跨项目经验收益。

本协议对应 Issue #691。此前 E46/E47 保持原终态和分母；新比较使用已移除 `diagnostic_paths` 的共同规划接口，跨批差值不能解释为修复的因果效应。

## 样本与顺序

六个项目，各两重复、三方法，共36次。jsoncpp/libite/highwayhash 为精确复用层；double-conversion/libogg/xxhash 为无方案层；每层各覆盖 CMake、Autotools、Make。前者方案固定取 E45 第一重复 Flash 的对应成功方案，不按费用或本轮结果挑选。后者在方法结果产生前固定精确 commit、公开任务和作者参考。参考失败保留且停止准备，不能根据某方法输赢替换项目。

新增项目源码和独立参考已经开发暴露，不能称严格 holdout。三项新来源未参加此前同项目方案实验；经验来源族与评价项目族隔离。三种方法六种排列各两次，每项目第二重复反转顺序，位置和紧邻前序平衡。重复不当独立项目。

## 三种方法

1. 基础 Forge：规划 Agent 只读作者材料、提交阶段命令，Workflow 执行，失败由同 Flash 返回修订方案。
2. 两层经验 Forge：先比较成功方案库与完整公开任务，除运行标签 `plan_id` 外均须相同。命中直接实际重建，跳过初始 Agent；未命中才在初始任务开始检索一次跨项目建议并规划。真实失败仍由同 Flash 恢复，每个新恢复任务开始检索一次；任务内不刷新。最多两条/4096字节，无匹配则弃权。复用与建议可以在同一执行入口共存。
3. 强工具 Agent：同 Flash、原始材料、容器执行权限和独立检查，自主决定读取、依赖、配置、构建、诊断和成功 recipe 提交；没有 Workflow 下一动作建议或历史经验。

所有方法保持原源码/测试，允许正常生成文件。同镜像、源码、并行资源、简洁目标和独立参考；Agent 不接收参考成功命令、精确产物路径或个人知识库。两 Forge 只差经验；强工具 Agent 的动作接口和编排本来不同，因此属于完整系统比较，不能称同 Harness 的纯状态因果。CXXCrafter 既有结果保留为外部参考，本批无第四方法。

## 成功方案与来源费用

方案库与建议库均为本批之前的固定快照。每次完整成功后仍保存 `verified-simple-recipe.json`，包括最终通过的构建动作和验证依据；不包含失败探索历史，不做最短指令优化。本批输出不读回库、不喂后续项目/重复，不将36次解释为在线学习。

精确匹配覆盖 URL、commit、源码归档、镜像、架构、目标/澄清和并行数。多份相同任务身份拒绝隐式选第一项。建议仍沿用 `matched_action_advice_v1`，本批不同时改检索算法。

历史经验提炼费及三份历史来源构建费另列，既不重复支付，也不把零在线模型费叫零投入。保存成功方案无需新增提炼模型。

## 结果与分析

主结果完整保留36次计划分母，同时报告：

- 主要构建完成与完整完成。作者测试、精确交付、clean replay、源码保持和 cleanup 逐层保留；主要构建成功但测试未通过必须单独解释。
- 全部初始规划、源码读取、结构纠正、失败和恢复的请求/Token/保守费用，强工具 Agent 总请求另列。初始/恢复费用依据实际 `agent.started` 和费用事件分项。
- 包含规划、构建、独立检查、重放和清理的总耗时；初始规划与恢复耗时另列。早停不能当加速。
- 精确方案命中、经验检索次数、补读次数、实际恢复和失败类型；提供执行轨迹案例。

总体、精确复用层、无方案层分别报告。总体只代表本次各半的混合比例，不外推部署任务分布。共同成功配对成本/耗时可作明确标注的辅助描述，不能替代全分母结果。不要求全部指标全面胜出；负结果与合理额外检查照实解释，不从额外请求本身推定无效。

作者测试使用实际所选构建系统对应入口，CMake 零测试不是通过。double-conversion 作者测试默认可选；如方法构建了主库却未注册测试，分开报告主构建与测试配置缺口，不撤销主要构建、不事后放宽检查。libogg 采用作者普通 `make check` 或实际 CTest；xxhash 采用作者 `make check`（包含 sanity 与 CLI 基本测试），不扩成跨平台/编译器/架构 CI 矩阵。

## 费用与停止

拟定新增费用共享硬上限2美元、有效时窗4小时，准备与执行的范围以本轮明确授权为准；当前准备不读取凭据或调用 Provider。正式运行须绑定此 identity、manifest SHA、用户授权及带时区截止。旧预算与时窗不续用。

单槽最多0.40美元、96请求、1,000,000记录Token停止阈值，沿用共同单响应保守预留和操作时窗。请求 `deepseek-flash`，响应只接受已登记 Flash 标识，thinking low，HTTP超时240秒、SDK `max_retries=0`。全部输入按缓存未命中0.30美元/百万、输出1.20美元/百万保守估费，不冒称账单。

自然失败保留、无自动重试、不补槽；未知用量、模型身份异常或清理失败停止整批。费用/时窗不足则保留未观察分母。原始请求、响应、日志、最终方案、分层结果、费用、清理与运行源码快照保存独立目录。零 Provider 参考/装配实跑仅支持执行实现，不进入模型效果分母。

## 执行

入口 `scripts/forge_two_level_system_comparison.py` 支持 `--prepare`、`--check-prepared`、`--run --authorization ... --output ...` 和只读 `--analyze ...`。复用 `forge_simple_comparison.execute` 与 `run_simple_system`，不修改历史 manifest、原始证据或失败。
